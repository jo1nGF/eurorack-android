# Eurorack Study Rack (Android)
Rack modular de estudo: Pamela's PRO Workout, Intellijel Scales, Mutable Plaits, Mixer e MIDI→CV.
- Interface/motor: `app/src/main/assets/index.html` (WebAudio). Ponte MIDI nativa: `MainActivity.kt`.
- Build: suba esta pasta num repositório GitHub (branch main) → aba **Actions** → "Build APK" → baixe o artefato `eurorack-study-debug-apk`.
- Instale o APK (permita "fontes desconhecidas"). Toque em ▶ Áudio para iniciar.
